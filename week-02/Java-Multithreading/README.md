# Java Multithreading

## Objective

Learn how to create and execute multiple threads using the `Runnable` interface and coordinate their execution using `join()`.

## Concepts Used

- Runnable Interface
- Thread Class
- Multithreading
- start()
- join()

## Implementation

- Create a class that implements `Runnable`.
- Create two threads using the same task.
- Assign custom names to the threads.
- Start both threads.
- Wait for both threads to finish using `join()`.

## Expected Output

Worker-1: Running task 1
Worker-2: Running task 1
