# Handling Arithmetic Exceptions in Java

## Objective

Learn how to handle runtime errors using a `try-catch` block and prevent the program from crashing when dividing by zero.

## Concepts Used

- Exception Handling
- try-catch
- ArithmeticException

## Implementation

- Divide two integers inside a `try` block.
- Catch `ArithmeticException` when dividing by zero.
- Print an appropriate error message.
- Continue program execution after handling the exception.

## Expected Output

Cannot divide by zero
Program completed
