# Custom Exception Handling in Java

## Objective

Learn how to create and use custom exceptions with `throw`, `throws`, and `try-catch`.

## Concepts Used

- Custom Exception
- Exception Handling
- throw
- throws
- try-catch

## Implementation

- Create a custom exception class named `InvalidAgeException`.
- Throw the exception if the age is less than 18.
- Handle the exception using separate `try-catch` blocks.
- Print "Access granted" for valid ages.

## Expected Output

Exception caught: Age must be 18 or older
Access granted
