# Java Collections Basics

## Objective

Learn how to use Java Collections to store data, remove duplicates, and preserve insertion order.

## Concepts Used

- List
- Set
- LinkedHashSet

## Implementation

- Store names in a `List`.
- Print the original list.
- Convert the list to a `LinkedHashSet` to remove duplicates while preserving insertion order.
- Print the unique names.

## Expected Output

Original List: [Alice, Bob, Alice, David, Bob]
Unique Names: [Alice, Bob, David]
