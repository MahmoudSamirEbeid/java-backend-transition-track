# Java Streams Basics

## Objective

Learn how to process collections using the Java Stream API.

## Concepts Used

- Stream API
- filter()
- map()
- sorted()
- collect()
- Method Reference

## Implementation

- Print the original list.
- Filter product names longer than 5 characters.
- Convert the names to uppercase.
- Sort the results alphabetically.
- Collect the results into a list and print them.

## Expected Output

Original List: [Laptop, Pen, Notebook, Headphones, Smartphone]
Filtered Products: [HEADPHONES, LAPTOP, NOTEBOOK, SMARTPHONE]
