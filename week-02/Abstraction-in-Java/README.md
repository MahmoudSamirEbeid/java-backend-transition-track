# Abstraction in Java

## Concepts Used
- Interface
- Abstract Class
- Inheritance
- Method Overriding
- Polymorphism

## Structure

- `Machine` → Interface defining the `start()` behavior.
- `Appliance` → Abstract class containing the common `name` field.
- `Fan` and `WashingMachine` → Concrete classes implementing the `start()` method.

Fan is running
